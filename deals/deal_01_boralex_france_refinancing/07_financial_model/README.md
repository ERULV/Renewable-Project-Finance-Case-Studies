# Financial Model

## Objective

Build a transparent educational model of platform cash flows, debt service and downside performance using public information and documented assumptions.

## Role in the Transaction Workflow

Converts the business, market, technical and financing analyses into measurable financial outcomes.

**Builds on:** Asset, market, technical and financing analyses.

**Supports:** Credit analysis, sensitivity analysis and investment committee recommendation.

---

## Deliverables

The analytical output for this workstream is documented in [`deliverable.md`](./deliverable.md).

- [ ] Model architecture and methodology
- [ ] Operating-portfolio forecast
- [ ] Revenue and operating-cost assumptions
- [ ] Development and capital-expenditure assumptions
- [ ] Debt schedule
- [ ] Cash waterfall
- [ ] DSCR and other relevant credit metrics
- [ ] Model checks and documentation

---

## Key Questions

- What are the primary cash-flow drivers?
- How should unavailable asset-level data be approximated?
- How is cash allocated between operations, debt service and equity?
- What debt-service capacity does the platform generate?
- Which assumptions have the greatest impact on results?
