# Investment Committee

## Objective

Prepare a concise internal decision package recommending whether and under what conditions the financing should be approved.

## Role in the Transaction Workflow

Transforms the detailed analysis into a clear decision, rationale and set of approval conditions.

**Builds on:** Executive summary, financial model, credit analysis, risk analysis and sensitivities.

**Supports:** Mandate confirmation, documentation and transaction execution.

---

## Deliverables

The analytical output for this workstream is documented in [`deliverable.md`](./deliverable.md).

- [ ] Committee memorandum
- [ ] Transaction and borrower summary
- [ ] Credit rationale
- [ ] Key financial metrics
- [ ] Principal risks and mitigants
- [ ] Conditions to approval
- [ ] Recommendation
- [ ] Supporting appendices

---

## Key Questions

- Should the bank approve the transaction?
- What is the central credit rationale?
- Which risks require explicit committee attention?
- What conditions should be satisfied before commitment or closing?
- What would cause the recommendation to change?
