# Transaction Execution

## Objective

Simulate how an approved financing progresses through mandate, due diligence, documentation, signing and financial close.

## Role in the Transaction Workflow

Demonstrates that completing a transaction requires coordinated execution, not only financial analysis.

**Builds on:** Investment committee approval and all supporting diligence.

**Supports:** Financial close assessment and post-mortem.

---

## Deliverables

- [ ] Indicative process timeline
- [ ] Mandate and initial pitch outline
- [ ] Information request list
- [ ] Due-diligence tracker
- [ ] Term-sheet reconstruction
- [ ] Documentation workstream
- [ ] Conditions-precedent checklist
- [ ] Signing and closing process
- [ ] Stakeholder and responsibility matrix

---

## Key Questions

- Which workstreams must be coordinated?
- Who is responsible for each deliverable?
- What must be resolved before signing?
- What conditions must be satisfied before funding?
- Where could execution be delayed or fail?
